Самые проблемные карточки

Как это работает
Выберите нужный урок из списка. Карточки загружаются из папки lessons в репозитории.
Укажите диапазон: например «с 15 по 20» — будут выбраны карточки №15–20 включительно.
Кнопка «Весь урок» отключает диапазон и выбирает все карточки текущего урока.
Без галочки они идут строго по порядку. С галочкой «Перемешать» меняется только порядок внутри выбранного диапазона или всего урока.
Статус каждой карточки обновляется автоматически: ⚪ новая, 🟡 изучается, 🔴 слабая, 🟢 хорошо знаю.

Письменно: вводите перевод, приложение проверяет его автоматически. При ошибке различия с эталоном подсвечиваются.
Ошибка / «Не знаю» запускают два возврата: через 5–10 заданий и ещё через 10–15 после первого.

Устно: произнесите перевод и нажмите «Проверить ответ». После сравнения с эталоном выберите:
Не знал — усиленное закрепление: три возврата примерно через 3–5, затем 5–8 и затем 10–15 заданий.
Почти / ошибся — два обычных возврата: через 5–10 и затем ещё через 10–15 заданий.
Знал — перейти дальше. Если это контрольный повтор, он считается успешно пройденным.

При новой ошибке цикл повторов для этой карточки запускается заново, без накопления лишних копий. Ваш корректный альтернативный письменный перевод можно сохранить кнопкой «Засчитать мой вариант».
